

You can run this tool using the following command "uv run main.py" followed by your question. You can add the flag "--verbose" for an indepth answer.

Use:
* This is an AI Agent that can work within a directory specified by the user. It read from and write to files and answer questions.

Tech
* OpenRouter: This AI Agent utilizes OpenRouter to find the best available free-use LLM.

Dependencies:
* OpenAI 2.44.0
* Python dotenv 1.1.0
